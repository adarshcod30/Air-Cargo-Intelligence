More flights, or fuller flights?

Freight is flights multiplied by the tonnes each one carries, so a year’s change splits exactly between the two. They need different responses: more flights needs slots and stands, fuller flights needs handling and warehousing.

How these are produced. Each series is fitted with SARIMA — a statistical model for seasonal time series — and checked by rolling-origin backtesting: the model is repeatedly asked to predict a month it was not shown, and the average error of those attempts is reported as MAPE. A 6% MAPE means past predictions were typically within 6% of what actually happened. Lower is better; a forecast without an error figure is a guess.

Projections

Predicted freight with an 80% interval — the range the model expects the true value to fall in four times out of five.

What counts as an alert. Seasonality is removed from each series, then months whose remainder is far from typical are flagged. Expected is what the seasonal pattern implied; observed is what was published. A large gap is not necessarily an error — a new terminal opening looks the same as a data problem, and both are worth a human look.

Why this exists. The data is assembled by agents that choose their own steps rather than following a fixed script. Each run records the goal, every tool it called, the reasoning behind the choice and what came back — so a figure can be audited back through the decisions that produced it. A tool called more often than the runs that used it is one an agent had to retry.
